Build a new app from this 3 line idea:
1. A minimal developer bookmark manager.
2. Saves URLs with title and tags in localStorage.
3. Clean dark mode UI with keyboard shortcuts.

Follow the Build Forge pipeline:
1. Run product-spec to create `docs/product-spec.md`.
2. Run project-bootstrap in new mode to create `.agents/project-profile.yaml` and render `AGENTS.md`.
3. Run scaffold-app to scaffold the project structure.
